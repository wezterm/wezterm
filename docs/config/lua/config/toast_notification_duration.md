# `toast_notification_duration = "Long"`

{{since('nightly')}}

Controls how long a toast notification stays on screen on Windows.

It applies to the notifications that are generated by the escape sequences
described in [notification_handling](notification_handling.md) and by
[window:toast_notification](../window/toast_notification.md). The other
notifications that wezterm shows, such as errors and the notification about
a new release, always use the long duration.

Possible values are:

 * `"Long"` - the notification stays on screen for around 25 seconds.
   This is the default.
 * `"Short"` - the notification stays on screen for around 5 seconds.

The system defines the precise durations, and the user may change them in
the accessibility settings of Windows; Windows doesn't allow an application
to specify an arbitrary one. Once the duration has elapsed the notification
moves to the notification center.

The [format-toast-notification](../window-events/format-toast-notification.md)
event can override the duration of an individual notification.

```lua
config.toast_notification_duration = 'Short'
```

This option has no effect on other systems.
