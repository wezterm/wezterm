# `toast_notification_silent = false`

{{since('nightly')}}

When set to `true`, Windows doesn't play its notification sound when wezterm
shows a toast notification.

It applies to the notifications that are generated by the escape sequences
described in [notification_handling](notification_handling.md) and by
[window:toast_notification](../window/toast_notification.md).

This is useful if you play a sound of your own; for example, from a
[user-var-changed](../window-events/user-var-changed.md) or a
[bell](../window-events/bell.md) event handler.

```lua
config.toast_notification_silent = true
```

The [format-toast-notification](../window-events/format-toast-notification.md)
event can override this for an individual notification.

This option has no effect on other systems.
